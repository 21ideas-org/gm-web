## Lightning & L2

#### Liquid Network restores full bitcoin backing for LBTC after September hack

A further 250 BTC was added to the reserves. Blockstream says all LBTC is again backed 1:1 by BTC, verifiable by anyone running a Liquid node. [news.bitcoin.com](https://news.bitcoin.com/blockchain/good-news-finally-liquid-network-restores-its-bitcoin-reserves/) [x.com](https://x.com/Blockstream/status/2117523199143407832)

#### Eclair tightens funding rules after unconfirmed inputs put Lightning payments at risk

The October 27 release requires confirmed inputs from peers for splices by default and improves recovery when a channel has to close while its funding is still pending. [cryptoslate.com](https://cryptoslate.com/eclair-tightens-bitcoin-funding-rules-after-unconfirmed-inputs-put-lightning-payments-at-risk/)

## Security & Privacy

#### BTCPay urges merchants to replace wallets after thefts estimated at $1.6 million

The November 2 advisory on the incident affecting BTCPay Server 2.4.1 and earlier ties the hot-wallet thefts to a flaw patched in August and says updating cannot remove access attackers have already gained. [cryptoslate.com](https://cryptoslate.com/btcpay-urges-bitcoin-merchants-to-replace-wallets-after-hackers-steal-an-estimated-1-6-million/) [blog.btcpayserver.org](https://blog.btcpayserver.org/btcpay-server-security-incident-2-4-1-and-earlier/)

#### Core Lightning nodes can keep crashing after an upgrade until a stored trigger is removed

The flaw was patched in April, but a malicious announcement already saved on an affected node has to be removed separately. [cryptoslate.com](https://cryptoslate.com/core-lightning-nodes-can-keep-crashing-after-an-upgrade-because-the-trigger-stays-on-disk/)

#### @mynodebtc urges upgrade to v0.3.52+ to prevent possible unauthorized access to nodes

The release mitigates TCP flaw CVE-2026-98432 and upgrades NodeJS (CVE-2026-111497) and Bitcoin (CVE-2026-117349). Raspberry Pi lacks a kernel TCP fix, so it gets mitigations instead: LND v0.21.6, new firewall rules and disabled MPTCP. [x.com](https://x.com/mynodebtc/status/2117418076069130380) [mynodebtc.com](https://mynodebtc.com/security)

## Technology & Development

#### Cashu's Nutshell 0.22.0 adds BIP-39 mint seeds and security fixes

It also brings updated payment requests, response caching without Redis and improved Lightning payment handling. Mint database migrations are included: back up databases and stop older mint workers before upgrading; Spark operators should reconcile pending payments first. [github.com](https://github.com/cashubtc/nutshell/releases/tag/0.22.0)

#### satd node adds optional OP\_RETURN value pruning

According to @bkeroack, satd is the first node implementation to offer this: values at or above a chosen size can be pruned at least 288 blocks behind the tip without breaking consensus, and -restoreopreturns restores them. The post cites the BIP-110 controversy. [delvingbitcoin.org](https://delvingbitcoin.org/t/full-op-return-value-pruning/3026) [delvingbitcoin.org](https://delvingbitcoin.org/t/cost-bounded-transaction-filtering-language/2966)
