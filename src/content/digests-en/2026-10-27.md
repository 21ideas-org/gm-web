## Security & Privacy

#### Keystone breach deepens: stolen device authentication key forces destruction of 18,835 hardware wallets

Hackers who breached Keystone's website obtained a device authentication key. The hardware wallet maker is suspending shipments, and personal information of nearly 26,000 customers was exposed. [news.bitcoin.com](https://news.bitcoin.com/security/keystone-breach-deepens-18835-crypto-hardware-wallets-face-destruction/) [x.com](https://x.com/KeystoneWallet/status/2114719318722404578)

#### Wasabi Wallet v2.8.5 brings security updates and drops payjoin sending

The release updates dependencies to address disclosed vulnerabilities and adds stricter transaction verification against malicious servers. Sending BIP78 payjoin transactions was removed to reduce attack surface; coinjoin stability fixes are included. [github.com](https://github.com/WalletWasabi/WalletWasabi/releases/tag/v2.8.5) [x.com](https://x.com/wasabiwallet/status/2114900859209540081)

#### BTCPay Server 2.4.6 released with further security hardening

Another security-focused release, with hardening especially around dependencies. Update via Server Settings → Maintenance → Update, or run the btcpay-update.sh script from the command line. [x.com](https://x.com/BtcpayServer/status/2114742606660063272) [github.com](https://github.com/btcpayserver/btcpayserver/releases/tag/v2.4.6)

#### Researcher solves bitcoin hacking challenge by proving a critical PHP flaw is exploitable

The challenge operator accepted the solve despite a wallet mistake; the harder question remains who turns such discoveries into deployed fixes. [cryptoslate.com](https://cryptoslate.com/bitcoin-hacking-challenge-finally-falls-as-researcher-proves-critical-php-flaw-is-exploitable/)

## Technology & Development

#### Liana 16.0 release candidate adds interface translations and taproot by default in the installer

The first release candidate adds French, Italian and Portuguese interface languages and BIP138 encrypted descriptor backups. Running it migrates the database: wallets opened with v16 can't be opened in v15 or earlier. [github.com](https://github.com/wizardsardine/liana/releases/tag/v16.0rc1)

#### Blockstream: Electrum connections on legacy ports stop serving data on November 9

Electrum users should switch to the new endpoints: port 50002 for TLS and 50001 for TCP. REST API users don't need to do anything. [x.com](https://x.com/BlockstreamHelp/status/2114664535801921623) [x.com](https://x.com/Blockstream/status/2114664672830095652)
