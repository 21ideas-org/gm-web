## Security & Privacy

#### Core Lightning v26.06.8 fixes a denial-of-service vulnerability in channel opening

Core Lightning v0.12.0 through v26.06.7 accept a channel open reusing another channel's funding outpoint, letting an attacker crash a node at no cost or, for only on-chain fees, put it in a crash loop until upgraded. Users should upgrade to v26.06.8. [delvingbitcoin.org](https://delvingbitcoin.org/t/disclosure-dos-vulnerability-fixed-in-core-lightning-v26-06-8/3072) [github.com](https://github.com/ElementsProject/lightning/releases/tag/v26.06.8)

#### Control of a Bitcoin browser extension with 50,000 installs is up for sale

CryptoSlate says the offer is separate from documented malware cases but shows how a buyer could acquire an extension's audience and control of its future updates. [cryptoslate.com](https://cryptoslate.com/50000-people-installed-this-bitcoin-browser-extension-now-control-of-it-is-up-for-sale/)

## Lightning & L2

#### Forced Lightning channel closes can be cheap but still leave funds waiting days, preprint finds

In the preprint's 2026 cohort of public force-closes, channels paid a median 925 satoshis, while the broadcaster's balance faced a median wait of 2.5 days. [cryptoslate.com](https://cryptoslate.com/a-forced-bitcoin-lightning-exit-can-be-cheap-and-still-leave-you-waiting-days/)

## Technology & Development

#### StartOS v0.4.3-rc.1 release candidate adds shared volumes and UPS monitoring

The prerelease adds shared local, external-drive and CIFS volumes with per-service access grants, automatic shutdown on low UPS battery, and security fixes that bound request sizes and end connections when access is revoked. [github.com](https://github.com/Start9Labs/start-technologies/releases/tag/start-os/v0.4.3-rc.1)

#### @nitesh\_btc builds a lightweight Rust and SolidJS rewrite of mempool.space

Built on rbitcoin and a gossip-only LDK node with SQLite storage, it needs no Electrum, Bitcoin Core, LND/CLN or MariaDB; it runs Mainnet, Signet, Testnet4 and Testnet5 from a home server, aiming first at feature parity. [x.com](https://x.com/nitesh_btc/status/2121769731631747506) [x.com](https://x.com/lightningdevkit/status/2121812905192808870)

#### Ali Sherief releases spscand, a watch-only scanner for BIP352 silent payments

Version 1.1.2 and its MIT-licensed C library libspscan never query a server about an address, output or transaction, scanning confirmed blocks via local Bitcoin Core RPC, a BlindBit Oracle server or BIP158 filters, each with different privacy trade-offs.
