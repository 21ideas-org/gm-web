## Security & Privacy

#### Bitcoin Core changes its security policy as AI makes bugs easier to find

Bitcoin Core says keeping certain vulnerabilities secret no longer offers much protection now that AI-assisted bug hunting has arrived. [cointelegraph.com](https://cointelegraph.com/news/bitcoin-core-changes-security-policy-as-ai-makes-bugs-easier-to-find)

#### @Core\_LN: CLN's currencyrate plugin may expose HTTPS requests to MITM attacks

Older webpki-roots versions (RUSTSEC-2026-0381) trust compromised emSign certificates. Core CLN and the Lightning protocol are unaffected; exposure is possible when using the default-enabled plugin's commands or bkpr-currency. A fix awaits upstream updates and a CLN release. [x.com](https://x.com/Core_LN/status/2113259577789575352) [x.com](https://x.com/AquaBitcoin/status/2113264121994965114)

#### Bisq v1.10.10 security update ships Tor 0.4.9.14

The release updates netlayer to v0.7.12 with the latest Tor security release, renews signing keys and refreshes bundled DAO data. @bisq\_network says it updates often to keep pace with Tor's roughly two-week releases and AI-driven bug discovery. [github.com](https://github.com/bisq-network/bisq/releases/tag/v1.10.10) [x.com](https://x.com/bisq_network/status/2113547111652524092)
