## Security & Privacy

#### Matt Corallo flags critical Linux kernel flaw; Lightning Labs ships LND mitigation

CVE-2026-98432, highlighted on October 30, is a use-after-free in the Linux kernel's IPv4 TCP handshake code, scored CVSS 9.8. [bitcoinmagazine.com](https://bitcoinmagazine.com/news/matt-corallo-flags-critical-linux-kernel-flaw-lightning-labs-ships-lnd-mitigation)

#### Core Lightning v26.06.10 fixes security vulnerabilities; developers urge upgrade

The point release fixes reported flaws in dual funding and splicing, onchaind HTLC resolution, gossip limits, connectd, runes and commando, plugin hooks and hsmd; tests for the fixes are temporarily withheld. [github.com](https://github.com/ElementsProject/lightning/releases/tag/v26.06.10)

#### Bisq v2.1.15 sandboxes its bundled Tor; update required to keep trading

The security update also includes the latest Tor security release and Java security updates, and Bisq now runs its bundled Tor on Linux as well as macOS and Windows. [github.com](https://github.com/bisq-network/bisq2/releases/tag/v2.1.15) [github.com](https://github.com/bisq-network/bisq/releases/tag/v1.10.11)

## Lightning & L2

#### Average new Lightning channel size reaches 2026 high of 0.45 BTC in October

October saw 6,892 channels opened with 3,102 BTC, and 86.1% of closes were cooperative, the highest share this year; 1,567 public channels opened in the week of Oct. 26–Nov. 1, up 7%. [x.com](https://x.com/ambosstech/status/2118055723259383835) [amboss.space](https://amboss.space/stats)

#### Dave Lund revises his design for a K-of-N Lightning node

Correcting an earlier post, he concludes that channel opens and updates need all N signers, with only closing K-of-N, and switches to the VPSS1 scheme from Komlo and Goldberg's Arctic (PKC 2025). [delvingbitcoin.org](https://delvingbitcoin.org/t/towards-a-k-of-n-lightning-network-node/2395#post_12) [delvingbitcoin.org](https://delvingbitcoin.org/u/zmnscpxj)
