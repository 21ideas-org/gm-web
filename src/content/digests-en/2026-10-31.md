## Security & Privacy

#### lnd v0.21.6-beta and v0.20.7-beta disable MPTCP listeners to mitigate a Linux kernel flaw

CVE-2026-98432 is a use-after-free in the Linux kernel's TCP stack; the demonstrated remote exploit needs an MPTCP listener. This is a mitigation, not a fix: Linux operators should also disable MPTCP on the host and install a patched kernel. Windows and macOS are unaffected. [github.com](https://github.com/lightningnetwork/lnd/releases/tag/v0.21.6-beta) [github.com](https://github.com/lightningnetwork/lnd/releases/tag/v0.20.7-beta)

#### StartOS v0.4.1 brings important security updates, Start9 urges prompt upgrade

The release adds opt-in conversion of existing backups to an authenticated filesystem format, named read-only backup snapshots, bearer tokens for API clients and an MCP server that lets AI agents call the StartOS API. [github.com](https://github.com/Start9Labs/start-technologies/releases/tag/start-os/v0.4.1) [x.com](https://x.com/start9labs/status/2116409940734824596)

## Lightning & L2

#### Lightning Labs' Wavelength is live on Bitcoin mainnet

According to a Lightning catch-up post, apps and AI agents can send and receive over Lightning with a few API calls, self-custodially, with no node or channels to manage. Wavelength VTXOs carry Taproot Assets secured by the Ark policy tree. Eclair and Core Lightning shipped security fixes. [x.com](https://x.com/givelightning/status/2115137385323479389) [x.com](https://x.com/lightning/status/2116295940319678601)

#### Chainalysis and TRM Labs link $6.3 billion Binance hack to North Korea

The firms tie the theft to North Korea's TraderTraitor group.
