## Security & Privacy

#### Bitcoin Core discloses CVE-2026-117348: node stall via duplicate orphan announcements

A peer could temporarily stall block and transaction processing. Affected: 29.0–29.5, 30.0–30.4, 31.0–31.2; fixed in 30.5, 31.3 and 32.1. The end-of-life 29.x series gets no fix. Medium severity; found by an automated LLM scan in Spiral's Project Loupe. [bitcoincore.org](https://bitcoincore.org/en/2026/11/20/disclose-orphan-inv-stall/) [github.com](https://github.com/project-loupe/loupe)

#### Bisq 1.10.12 patches Java4Shell and adds stablecoin payments for BTC trades

Bisq urges updating even if not trading: the bundled Java 21 runtime is updated to fix Java4Shell (CVE-2026-114938), which could let attackers run code, and the latest Tor security release is included. Updating is required to keep trading. [github.com](https://github.com/bisq-network/bisq/releases/tag/v1.10.12) [x.com](https://x.com/bisq_network/status/2123618478305530297)

#### LNbits advisory: webhook SSRF lets unauthenticated callers probe internal networks

The callback allowlist can be bypassed with an "@" in the URL and is also ignored, so a settled payment's webhook can reach internal hosts and cloud metadata; 200 vs 404 statuses reveal open ports, internal paths and IAM role names. [github.com](https://github.com/lnbits/lnbits/security/advisories/GHSA-qjqm-577g-5q7x)

## Technology & Development

#### Bitcoin Optech #432: decentralized pool payouts, Eclair DoS disclosure, stale tip relay

The newsletter analyzes decentralized mining pool payouts, covers the disclosure of a fixed denial-of-service vulnerability in Eclair, and links to continued debate on whether stale tip relay should include block data. [bitcoinops.org](https://bitcoinops.org/en/newsletters/2026/11/20/)

#### Researchers say Liquid's Confidential Transactions were quantum-upgradable all along

Per a paper by Yevhen Hrubiian, Mykyta Redko and @real\_or\_random, every Liquid output already encrypts its amount, so if a quantum computer nears, a soft fork could make spenders prove commitments match it, blocking hidden inflation without expiring coins. [x.com](https://x.com/blksresearch/status/2123314676175888757) [x.com](https://x.com/Blockstream/status/2123897764711153926)

#### Post-quantum recovery framework outlined for coins not migrated in time

adiabat defines PQ recovery as a consensus change adding spending conditions to existing UTXOs to protect them if elliptic-curve security breaks, separates prepared from unprepared schemes, focuses on the latter and invites feedback. [delvingbitcoin.org](https://delvingbitcoin.org/t/post-quantum-recovery-framework/3099) [delvingbitcoin.org](https://delvingbitcoin.org/#p-9093-what-is-pq-recovery-prepared-and-unprepared-1)
