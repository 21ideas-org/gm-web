## Price & Market

#### Bitcoin drops below $64,000 as weekend liquidations wipe out bullish bets

CoinGecko showed BTC near $65,500 on the afternoon of Nov. 14, while Newhedge recorded long-liquidation events below $66,000. [cryptoslate.com](https://cryptoslate.com/bitcoin-drops-below-66000-as-bullish-bets-get-wiped-out/)

## Security & Privacy

#### Core Lightning v26.06.8 fixes a denial-of-service vulnerability

Versions v0.12.0 through v26.06.7 let a peer reuse another channel's funding outpoint to crash the node at no cost; a closed-channel variant, costing only on-chain fees, makes the node crash-loop on restart until upgraded. Users should upgrade. [delvingbitcoin.org](https://delvingbitcoin.org/t/disclosure-dos-vulnerability-fixed-in-core-lightning-v26-06-8/3072) [github.com](https://github.com/ElementsProject/lightning/releases/tag/v26.06.8)

#### Control of a Bitcoin browser extension with 50,000 installs is up for sale

The offer is separate from documented malware cases, but it shows how buyers can acquire an extension's audience and control over its future updates. [cryptoslate.com](https://cryptoslate.com/50000-people-installed-this-bitcoin-browser-extension-now-control-of-it-is-up-for-sale/)

#### Ali Sherief releases spscand, a watch-only scanner for BIP352 silent payments

Version 1.1.2 and its C library libspscan are MIT-licensed. It never queries a server about addresses or transactions and can compute tweaks locally via Bitcoin Core 25+; BlindBit-based modes expose the IP (absent Tor) and online times to that server. #### Specter Desktop v2.3.0 released without a Windows GUI installer

The Windows installer build hung on CI and is due with v2.3.1; the Windows specterd daemon is included. Users are advised to create a full backup before migrating or switching to an Electrum-based installation. [github.com](https://github.com/cryptoadvance/specter-desktop/releases/tag/v2.3.0)
