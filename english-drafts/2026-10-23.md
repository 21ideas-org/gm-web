## Security & Privacy

#### @Core\_LN: outdated webpki-roots may expose CLN's default currencyrate plugin to MITM attacks

Older webpki-roots versions (RUSTSEC-2026-0381) trust compromised emSign intermediates. Exposure arises when using the plugin's commands or bkpr-currency; core CLN and Lightning are unaffected. A fix awaits upstream updates and a CLN release; meanwhile, disable-plugin=cln-currencyrate if unneeded. [x.com](https://x.com/Core_LN/status/2113259577789575352) [x.com](https://x.com/AquaBitcoin/status/2113264121994965114)
