#### Build and run your own COLDCARD firmware

Coinkite's guide shows how to modify, build and install COLDCARD firmware yourself: the source tree ships a development signing key, and the unchangeable bootloader marks such builds with a warning and a forced boot delay so they cannot pass as factory firmware. Use a blank development unit only. [blog.coinkite.com](https://blog.coinkite.com/build-run-custom-coldcard-firmware/) [github.com](https://github.com/Coldcard/firmware/tree/948dc108a0a1)
