## Lightning & L2

#### Bitcoin may go quantum-safe while Lightning privacy stays exposed

PQLN protects five off-chain surfaces with sub-millisecond cryptography, but its default design drives gossip downloads up 10.2 times. [cryptoslate.com](https://cryptoslate.com/bitcoin-may-go-quantum-safe-while-lightning-privacy-stays-exposed/)

#### Core Lightning v26.06.8 released with fixes for responsibly reported vulnerabilities

The point release ships bug fixes plus security fixes from multiple reporters, with no embargo period. A few tests are temporarily withheld to slow reverse-engineering; operators are urged to upgrade promptly. [github.com](https://github.com/ElementsProject/lightning/releases/tag/v26.06.8)

## Technology & Development

#### umbrelOS 2.0 ships as the project's biggest update yet

The release adds a Photos app, iPhone and Mac apps, virtual machines for Windows, Ubuntu and Android, multiple user accounts, an MCP server for AI agents, a Storage Manager with RAID, GPU acceleration and a new App Store. [github.com](https://github.com/getumbrel/umbrel/releases/tag/2.0.0)

#### Proposal: Asynchronous Pipeline Consensus decouples mining from full-block validation

The framework has miners start on block n+1 after verifying the compact block, deferring full-block validity to a 1-bit header field at n+k. A 10MB simulation suggests about 66.7 TPS with unchanged difficulty. [delvingbitcoin.org](https://delvingbitcoin.org/t/asynchronous-pipeline-consensus-decoupling-mining-from-full-block-validation/2906) [eprint.iacr.org](https://eprint.iacr.org/2026/141)

#### Pre-BIP draft standardizes an exposure classification for existing outputs

Duncan0k's draft, built on wallet-side feedback, classifies whether an output's public key has been exposed. Review now moves to pull request #2294 on the bitcoin/bips repository, where publication depends on the response. [delvingbitcoin.org](https://delvingbitcoin.org/t/standardizing-an-exposure-classification-for-existing-outputs-pre-bip/2866#post_12) [delvingbitcoin.org](https://delvingbitcoin.org/u/anzus_gemwallet)
