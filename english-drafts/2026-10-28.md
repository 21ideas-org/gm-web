## Security & Privacy

#### Bitcoin Core v31.1 fixes a -privatebroadcast privacy bug

The release fixes a path that could connect over clearnet even with the privacy network enabled; anyone using -privatebroadcast should update promptly. [delvingbitcoin.org](https://delvingbitcoin.org/t/bitcoin-core-v31-1-released/2696#post_2)

#### OpenAI claims a cryptography breakthrough: does it threaten Bitcoin?

The claim concerns the Exponential Time Hypothesis, and a theoretical SAT speed-up alone does not establish a practical cryptographic attack. [cryptoslate.com](https://cryptoslate.com/openai-claims-a-math-breakthrough-does-that-threaten-bitcoin/)

## Lightning & L2

#### Lightning tightens invoice rules after a reported attack made Bitcoin withdrawals look unpaid

BOLT11 now requires one payment hash and one payment secret, while operators must check how their software records withdrawals. [cryptoslate.com](https://cryptoslate.com/lightning-tightens-invoice-rules-after-reported-attack-made-bitcoin-withdrawals-look-unpaid/)

#### Eclair v0.14.6 patch release brings security hardening fixes

ACINQ recommends upgrading, as some of the issues can be exploited by malicious nodes. A new setting controls whether splices can spend unconfirmed inputs (off by default); the release is fully compatible with previous versions. [github.com](https://github.com/ACINQ/eclair/releases/tag/v0.14.6)

#### Liquid Federation says BTC-LBTC swaps are re-enabled as part of a staged recovery

Swaps run 1:1 via participating providers that handled 99% of peg-out volume before the incident; normal peg-outs stay under enhanced controls as an independent security audit nears completion, and full 1:1 BTC backing for LBTC is still being restored. [x.com](https://x.com/Liquid_BTC/status/2115201117789245837) [x.com](https://x.com/AquaBitcoin/status/2115210194133156225)
