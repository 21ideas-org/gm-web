## Technology & Development

#### conduition opens a discussion on safely handling large post-quantum signatures in Bitcoin script

No PQ signature scheme available today except isogenies fits the 520-byte stack element limit. A draft BIP, now being rewritten, would raise it to 6kb, which poses DoS risks to nodes; an open Bitcoin Core PR would store stack elements as reference-counted objects. [delvingbitcoin.org](https://delvingbitcoin.org/t/handling-pq-signatures-on-the-stack/3128) [github.com](https://github.com/bitcoin/bitcoin/pull/36721)

#### Fedimint v0.13.1 fixes mint fee, startup panic and iroh lockup bugs

The drop-in bug-fix release has no consensus, API or database format changes and restores federations with non-default mint fees. Everyone on v0.13.0, including guardians, gateway operators and app developers, should upgrade. [github.com](https://github.com/fedimint/fedimint/releases/tag/v0.13.1)

#### Blockstream app 3.7.0 adds Jade Bluetooth connections on Windows, macOS and Linux

The release adds AMP2 account renaming and archiving and Ledger transaction review pages, blocks Jade units that fail the genuine check, redacts wallet data from support logs and raises the minimum Jade firmware to 1.0.42. [github.com](https://github.com/Blockstream/green_qt/releases/tag/release_3.7.0)
